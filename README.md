# Волна

Хакатон-MVP: соцсеть для подростков-волонтёров и организаций. Здесь можно искать проекты, подавать анкеты, общаться с организаторами, считать часы и собирать подтверждённое портфолио.

## Две версии

Роль выбирается при входе и переключается в «Настройки → Аккаунты».

**Волонтёр:** Главная · Лента · Календарь · Уведомления · Профиль
**Организация:** Кабинет · Лента · Календарь · Уведомления · Профиль

## Возможности

| Раздел                       | Что умеет                                                                                                                                                                                                                                                      |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Главная `/`                  | Поиск в углу, «Для вас» — сторисы по темам (можно создать свою тему, видимую всем), вкладки «Все / Проекты / Тренинги / Разовые акции / Встречи / Наборы / Напомнить позже», карточки-постеры с кнопками «Податься», «Напомнить позже» и «Вопрос организатору» |
| Мероприятие `/o?id=`         | Постер, точные задачи, требования, участники; у организатора — уведомление, вопросы, продвижение                                                                                                                                                               |
| Анкета                       | «Податься» открывает анкету организатора; организатор собирает её в конструкторе                                                                                                                                                                               |
| Уведомления `/notifications` | ИИ-помощник, новые события, мероприятия → уведомления → чат с вопросами; организатор создаёт уведомления и отвечает                                                                                                                                            |
| Лента `/feed`                | Рекомендации: короткие видео, фото, длинные видео, текст; «Опыт» — отзывы с фото и видео; лайки, комментарии                                                                                                                                                   |
| Профиль `/profile`           | Постер, аватар, ФИО, возраст, город, счётчики (подписчики, часы, проекты, сертификаты), сетка постов, редактирование                                                                                                                                           |
| Кабинет наград `/awards`     | Полки с медалями, кубками и сертификатами; организация создаёт награды и вручает участникам                                                                                                                                                                    |
| Портфолио `/portfolio`       | Часы, проекты, организации, награды, заявки на подтверждение часов                                                                                                                                                                                             |
| Календарь `/calendar`        | Дни участия отмечаются после подтверждения заявки, напоминание накануне, фото к дням                                                                                                                                                                           |
| Поиск `/search`              | Волонтёры, организации, мероприятия                                                                                                                                                                                                                            |
| Кабинет `/cabinet`           | Папки «Заявки», «Волонтёры» (сколько мероприятий посетили), «Подтверждение часов»; «+» — публикация; продвижение                                                                                                                                               |
| Настройки `/settings`        | Руководство, учётная запись, аккаунты, стиль приложения, архив мероприятий, конфиденциальность                                                                                                                                                                 |

## Демо-режим

- SMS и письма не отправляются: подходит любой 4-значный код. На экране входа есть демо-вход за волонтёра и за организацию.
- ИИ-помощник работает по прозрачным правилам (дедлайны, заявки, часы, интересы); в проде его можно заменить вызовом LLM.
- Продвижение не списывает деньги, охват примерный.
- Данные хранятся в `localStorage`; вернуть исходные — «Настройки → Учётная запись → Восстановить демо-данные». Фото сжимаются перед сохранением, загруженные видео живут до перезагрузки.

## Стек

SvelteKit 3 (Svelte 5), Tailwind CSS 4, Lucide, Bun, adapter-static (каждая страница собирается в статический HTML, деплой на Vercel без настройки).

```sh
bun install
bun run dev
```

## Проверки

```sh
bun run check
bun run lint
bun run build
```
