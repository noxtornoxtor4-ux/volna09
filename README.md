# Волна

Хакатон-MVP: платформа и социальная сеть для подростков-волонтёров и организаторов. Здесь можно искать проекты, делиться опытом, считать часы и собирать подтверждённое диджитал-портфолио.

## Экраны

| Экран              | Маршрут               | Что умеет                                                                                                                                     |
| ------------------ | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Лента возможностей | `/`                   | Карточки проектов, тренингов, акций, встреч и наборов; «Для вас» по интересам; поиск и фильтры; «Податься сейчас» и «Напомнить позже»         |
| Лента опыта        | `/feed`               | Посты с фото и вертикальными видео, лайки, комментарии, «поделиться», отметка проекта и организации                                           |
| Профиль            | `/profile`            | Счётчик подтверждённых часов, форма добавления часов, календарь (прошлые и запланированные дни), история участия с ролями, сертификаты, клубы |
| Кабинет куратора   | `/organizer`          | Конструктор мероприятий с предпросмотром, заявки волонтёров, подтверждение участия и часов                                                    |
| Вход и настройки   | `/login`, `/settings` | Вход по телефону (SMS-код) или email (пароль или ссылка), редактирование профиля, выбор акцентного цвета и тёмной темы                        |

Экраны связаны: заявка из ленты попадает в кабинет куратора, подтверждённые куратором часы — в портфолио волонтёра, созданное мероприятие — в ленту возможностей.

## Демо-режим

- SMS и письма не отправляются: подходит любой 4-значный код.
- Данные хранятся в `localStorage`. Вернуть исходные можно в «Настройках» кнопкой «Восстановить демо-данные».
- Загруженные видео живут до перезагрузки страницы; фото и документы до 1,5 МБ сохраняются.

## Стек

SvelteKit 3 (Svelte 5), Tailwind CSS 4, Lucide, Bun.

```sh
bun install
bun run dev
```

## Проверки

```sh
bun run check
bun run lint
bun run build
```
