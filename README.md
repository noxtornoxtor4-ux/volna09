# TestBoost AI (ORT-Prep AI)

Хакатон-MVP: подготовка к ОРТ, ЕГЭ и SAT, где ИИ не просто проверяет ответы, а объясняет ошибки.

- **Пробный тест** (`/app/test`): формат экзамена, таймер, навигация, балл по шкале экзамена
- **Разбор ошибок**: у каждого неверного варианта своё объяснение, пошаговое решение, «Объясни проще» и вопросы ИИ-репетитору
- **Тренажёр** (`/app/practice`): генератор похожих задач с новыми числами для слабых тем
- **Прогресс** (`/app`): график баллов, прогноз, карта знаний, план на сегодня
- Лендинг (`/`) с интерактивным демо и калькулятором экономии, материалы для жюри (`/pitch`)

## Стек

SvelteKit 3 (Svelte 5), Tailwind CSS 4, Lucide, Bun. ИИ: OpenAI API (необязательно).

## Запуск

```sh
bun install
bun run dev
```

Без `OPENAI_API_KEY` ИИ-репетитор отвечает встроенными разборами задач. Чтобы включить OpenAI, скопируйте `.env.example` в `.env` и укажите ключ.

Прогресс хранится в `localStorage`. При первом входе показывается демо-история ученика, сбросить её можно в боковом меню кабинета.

## Проверки

```sh
bun run check
bun run lint
bun run build
```
